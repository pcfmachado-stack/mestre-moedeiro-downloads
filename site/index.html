Dúvidas frequentes

O Mestre Moedeiro é gratuito?

Sim. O Mestre Moedeiro é distribuído gratuitamente pelo Mundo Numista.

Preciso instalar Python?

Não. O instalador reúne os componentes Python utilizados pelo aplicativo.

Preciso de internet para usar?

A ativação inicial exige conexão. Após a ativação, as funções locais já testadas funcionam offline. Recursos que acessam a loja exigem internet.

Como recebo novas versões?

O botão de download desta página aponta sempre para a versão atualmente publicada pelo Mundo Numista.
